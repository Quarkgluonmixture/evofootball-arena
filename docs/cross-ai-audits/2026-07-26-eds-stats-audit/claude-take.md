# Claude 独立分析 — EDS 链统计与闸门设计审计(2026-07-26,写于读 Codex 报告之前)

按我对链条的全程知识,严重度降序。

## 1. 簇内相关被当独立样本(伪重复)— 最可能是真伤

多个闸的功效计算把"时刻/传球"当独立抽样:G1 的 SE≈1.29pp 按 n=3,000 独立算;
census 校准 SE 按 21k 传球独立算(实际来自 250 场,比赛内/回合内强自相关);
E5c 的 pattern/control 臂同理。同一场比赛里的时刻共享阵容、比分状态、体能、
战术相位——有效 n 显著小于名义 n。后果:所有"±X pp 带宽 ≈ Yσ"的功效声明
系统性乐观,过去按 3.4σ 设计的闸可能实际只有 2σ 出头。
修法:cluster-robust SE(按比赛聚类)或 block bootstrap 重算历史闸的真实功效;
今后契约把"聚类单位"写进功效计算的必填项。

## 2. argmax 消费者的赢家诅咒 — 未来 E4-2 校准的预埋地雷

表是带噪声的估计;chooser 取 argmax。被选中的选项系统性偏向"估计误差为正"
的那批(选择作用于噪声),所以"被选中选项的实测表现"必然低于其表面价格——
即使表整体校准完美。E5d Phase 1 的部署人群校准(C2)是在全候选集上做的,
没问题;但船后若有人对"被选中的传球"做 realized-vs-predicted,会看到系统性
shortfall 并误判为表坏了。这是统计构造,不是缺陷。
修法:任何对 chosen 子集的校准检验必须预先声明预期 shrinkage(可用表的每桶
SE 推出数量级),或只在全候选集/随机化子集上做校准。

## 3. 价值 horizon(240 tick)的敏感性从未被探测

V = "尝试后 240 tick 内射门"。4 秒是设计常数,直接塑造整张价值表——
E5 中心假设的 FAIL/PASS 可能对 horizon 选择敏感(三人配合的价值窗口天然
比直塞长)。链条里没有任何 horizon 敏感性探针。
修法:同一批 fork 免费重算 3–4 个 horizon(120/240/360/480)下的表与
re-rank 结论;若结论翻转,horizon 本身要么按现实锚定要么成为测量对象。

## 4. 闸门族的族错误率没有链级预算

单闸功效已成文(第六类阈值、继承值重算功效),但一次审计跑 28–32 道闸、
链条累计数百道,从没有"每次审计预期 false fire ≈ Z 道"的族级声明。
C3 的桶开火(1.59σ)事后诊断为噪声,正确;但下一次开火仍要靠人肉判断
"是真是噪"。修法:每份契约的闸门表加一列"该闸在 H0 下的开火概率",
底部合计 = 本审计的预期噪声开火数;实际开火数超预算才停队列,
单道 <2σ 开火自动降级为"报告项+复测"。

## 5. 船后再普查节奏缺席(分布漂移)

所有表在 legacy-brain 世界测得;新 chooser 上线后部署分布即刻漂移
(表改变世界,世界又是表的测量对象——反馈回路)。#8 只登记了"v1 够用,
之后重访",没有触发条件。修法:ship 时同步预注册漂移监视器
(每 N 代重测 marginal,偏离 >带宽 则触发再普查)——把"重访"变成闸。

## 6. 20–80 支配带是发明的常数

对"situational"的操作化(≥20%、≤80%)自己就是没出处的数字——正是这条链
处处禁止的东西。现实足球有传球力度分布可锚定(高力度传球占比)。
修法:REALISM-LEDGER 里给它锚点,或降级为报告项 + 用分布距离度量替代。

## 7. 小项

- fingerprint 只覆盖 seed=1337 一条配置路径;行为回归可从其它 seed 溜过
  (缓解:744+ 测试、双跑哈希;残余风险低但存在)。
- 风格熵中位数 n=5,方差巨大(0.78–3.4);过是大幅过,但该统计量本身
  对种子极敏感,长期应换更稳的多样性度量(如跨队距离矩阵的特征值谱)。
- E2b-0 曲线在 flag-OFF 世界测得,E5 又在其上叠 V 表——两张表的误差
  相关性(同一批 fork 衍生)从未建模;乘积 P̂×V̂ 的置信带因此被低估。

## 三条最影响"是否发船"的

1. 簇内相关 → 历史闸的真实功效需要一次性重估(便宜:数据都在)。
2. 赢家诅咒 → E4-2 及船后的一切 chosen-子集评估必须预声明 shrinkage。
3. 漂移监视器 → ship 的定义里加进再普查触发器,否则表的诚实性有保质期。
