## 游戏现在是什么

- 6 对 6 的 AI 球队在浏览器里踢联赛和杯赛，战术和球员特质随赛季进化。玩家目前只能看，不能操控。
- 默认打开的是最早的"原版世界"。之后做的 19 个改进版本是一层层叠起来的，都要加 `?a4world=N` 才能打开。
- 后台快速模拟的联赛赛季，跑的也是原版世界（`League.fromJSON` 不带比赛开关）。
- 画面：three.js 程序生成的小人、程序动画、第三人称镜头。最近一次画面改动在 2026-09-15。
- GitHub Pages 部署从 2026-09-23 起关闭。

## 决定（2026-11-06，用户：「都默认」）

1. **下个月的验收标准**：不带任何参数打开游戏，眼睛看得出更像足球。
2. **第 19 版不采用**。进球少约 7%，换来的只是每 190 个地面传球少 1 个打到对手。它的两个开关留在代码里，默认关闭。
3. **第 18 版升为默认，后台联赛也跑它。** 第 18 版已经包含 12–17 版（`a4MatchFlags` 逐层叠加），所以这几个待看的门一并关闭。前提是先跑一次第 0 版对第 18 版的多赛季对比，风格多样性不能塌。
4. **流程分级**：小改动只做一次 A/B，加一节说明，不再走一步一份文档的长链条。开工前先写一句"用户会看到什么"；预计肉眼看不出的改动按数据决定，不送去给用户看。每周最多 3 项请用户看；用户没回复就暂停，不自动回退。
5. **文档**：只有 `VISION.md` 和本页是给人看的。其余是档案，见下面"档案在哪"。
6. **合流完成、第 18 版成为默认之后，重开 GitHub Pages。**
7. `docs/world-model/data/` 的实验数据 JSON 以后不再进 git。已经在历史里的不改写。
8. 骨骼动画、赛中交互本月不做，下个月再议。
