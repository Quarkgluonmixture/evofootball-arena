## 第 0 版对第 18 版的多赛季对比（2026-11-06）

复算：`fnm exec --using=26.3.0 npx tsx scripts/world-compare.ts --seeds <种子>`，每个种子 10 季全长比赛；种子 424242,31313,1337 和 7,99,2026,555,8080 各跑一次，共 8 个。下面是 8 个种子的平均（第 0 版 → 第 18 版）：

- 每场进球 2.57 → 3.03
- 10 季里不同冠军数 6.5 → 7.3
- 球队特质差异（spreadMean）基本不变（约 0.159 → 0.159）
- 最后一季还在用的进攻阵型种数 2.9 → 2.0；防守阵型 2.4 → 2.5
- 单一阵型最多占几家球队（16 家里）14.4 → 14.6

结论：第 18 版没有让多样性明显变差，所以升为默认；但两个世界的阵型都高度趋同，这是要单独处理的老问题（下一步第 3 条）。
