## §N — THE EX-ANTE POWER ARITHMETIC (shown BEFORE any battery ran)

DV-T1 sized itself off an **inherited, out-of-world MDE** (O2-T1's paired delta on
`trueContextShare`) because no same-world paired delta existed. One exists now: DV-T1's own battery
published **the very quantity this extension exists to resolve**. So this stage's N rule is a
**power rule with a published variance**, not an MDE guess.

**The inputs, read from the committed artifact
[`data/dv-t1-map-exam.json`](data/dv-t1-map-exam.json) → `preRegisteredPrimary.allArms.planeAnchor.supplyLimb`:**

| input | value |
| --- | ---: |
| source clusters `nSource` | **283** |
| anchor supply point estimate (`trueHoldableShare`, ARM − control) | **+0.001344** |
| its 95 % paired-cluster CI | **[−0.000076, 0.002758]** |

**The arithmetic, in four steps:**

```text
1  half-width  = (0.002758 − (−0.000076)) / 2                     = 0.001417
2  se(283)     = half-width / z.975   = 0.001417 / 1.959963985     = 0.000722972
3  se(needed)  = |point| / (z.975 + z.80) = 0.001344 / 2.801585    = 0.000479728
4  N           = ceil( 283 · (0.000722972 / 0.000479728)² )        = ceil(642.75) = 643
```

Step 2 recovers the bootstrap SE from a 2.5/97.5 percentile interval. Step 3 is the standard
80 %-power identity at 95 % two-sided — the same `(z.975 + z.80)` this family's N rule has always
used. Step 3→4 uses the fact that a **paired cluster** bootstrap's SE scales as `1/√N` in the
number of **clusters** (#20: cluster = match seed).

**N\* = 643.** Ledger room is **800** (`binds = false`); the dispatch cap is **900**
(`binds = false`) — ⭐ **neither ceiling binds, so the battery runs the power rule's own N.** The
MDE actually bought at N\* is **0.001343734**, i.e. the anchor's own replicated estimate, which is
the point.

⚠ **WHAT THIS RULE ASSUMES, DECLARED.** That this stage's per-seed cluster variance on
`trueHoldableShare` is DV-T1's. Same world, same rulers, same three arm configurations, same
estimator — but **different seeds**, so it is an assumption. It is the honest one available ex
ante, and the probe prints the **realised** half-width beside the **ex-ante expected** one
(0.000940064) so the reader can see whether it held.

⚠ **AND WHAT IT DOES NOT CLAIM.** Resolving an estimate is not the same as the estimate being real.
A CI that still straddles zero at N\* is **route (c)**, and route (c) is the commander's.

**G-N** is the gate: the frozen literal `N_FROZEN = 643` must equal the derivation, the moments
