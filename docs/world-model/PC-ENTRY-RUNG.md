**THE PROBLEM IT SOLVES.** M-PC.3 wipes the recognition book every season and a book is born

**THE FORM: PC-T2's arm-C dose EXACTLY, by the same pooling law, in the same words.** At the
construction of the **watched** match each of the two teams' recognition books is **reset and
re-filled** from PC-T1's committed `perBookCells[].armsByBodyCell`, with PC-T2's own arithmetic
(that stage's §FORM, verbatim):

> `dose[rosterIdx][cell] = round( Σ_books Σ_sides armsByBodyCell[side·9 + rosterIdx][cell] ÷
> (books × sides × seasons) )`

— **12 books × 2 sides × 8 seasons = 192**, the MEAN END-OF-SEASON book of a roster SLOT.

* **Written through the book's own public `note(rosterIdx, key)`**, PC-T2's `dosedBooks` idiom
  verbatim: the only way a cell moves in the shipped seam, so a dosed book is a state the world
  could itself have reached. No field surgery, no new capability, no writer that does not exist.
* **Read from the artifact at run time, never typed**, and the entry's pooling is proven
  **bit-equal to the table PC-T2 committed** (`frozen.doseProvenance.table`) — a pin, not a claim.
* ⭐ **THE GUARD HASHES FILE BYTES** (canon, home ruling #289 item 1). The artifact is imported as
