## §0 THE FIVE BLIND SPOTS (what eyes + current rulers cannot see)

1. **ABSENCE** — the eyes cannot see what does not exist (CB-C0's "0
   challenges from behind" was found by accident, not by a ruler).
2. **BETWEEN-TEAM DIFFERENCE** — emergent 战术/风格 requires measurable
   behavioural variance between teams; nothing measures whether all 20 teams
   play the same football.
3. **SEASON-GRAIN PHENOMENA** — table spread, home advantage, score-tail
   drama: invisible at match grain.
4. **SEQUENCE STRUCTURE** — 配合 is chain-shaped; scattered counters exist
   (dupRun/thirdMan) but no chains-vs-shuffled-baseline ruler.
5. **THE GAP TABLE IS NOT AN INSTITUTION** — the 2026-08-08 "ours vs real"
   census (#170–#173) was one-shot; no arc since has re-run it.

## §1 The instruments

* **R-甲 — THE EVENT-VOCABULARY CENSUS** (one-shot, instrument-only): a
  frozen vocabulary of real football's event/action types — drafted FROM THE
  SPORT, before the engine is consulted (⭐ the freeze order is the
  instrument: a list drafted by reading the engine shapes itself around what
  exists — the list-shaped blind spot). Each entry classified
  PRESENT / DEGENERATE / ABSENT in the engine, with evidence (code trace
  file:line or measured occurrence). Output = the absence map the eyes can't
  produce.
* **R-乙 — THE STANDING GAP TABLE** (an institution, not a one-shot): ~15
  quantities with published real-football distributions; columns = OURS
  (measured, CIs) / REAL (cited source + confidence) / STATUS (deliberate
  arcade deviation · gap · unknown — adjudicated by ruling, never silently).
  The #170-vetted real values inherited where they exist; the pitch×numbers
  menu item folds in as a named extension. ⭐ RE-RUN CLAUSE: re-run after
  every arc that lands a world-facing mechanism; drift between runs is
  REPORTED to the ruling chain.
* **R-丙 — THE STYLE-DISPERSION RULER** (named, queued after 甲/乙):
  between-team behaviour-vector dispersion. Expected reading TODAY = zero
  (style genes born absent) — the baseline IS the point; layer 3+/evolution
  arcs make it the aesthetic criterion's main table.

## §4 Non-claims

arcade doctrine stands). No src change. No claim that the vocabulary or the
table is complete — both are versioned and amendable by ruling; a missing row
indicts the version, not the idea (the six-source ledger's own completeness
rule, applied to rulers).
