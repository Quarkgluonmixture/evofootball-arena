## §6 — SIZING (the arithmetic from the P3p-2 variance anchors; the smoke; the N rule; the cap)

The bands are relative to THIS battery's R0; the P3p-2 run (N=120 @ 11.1M, nearby
fresh seeds, `906c6449…930f14`) supplies the variance ANCHORS. CI half-widths
scale as `1/√N` (paired match-seed cluster bootstrap, matches = clusters), so
`SE_N = SE_120 · √(120/N)`. "Resolve the gate either way at ~95 % power" = at the
true value, `P(the 95 % CI excludes the band edge) ≈ 0.95`, i.e.
`gap ≥ (z_.975 + z_.95)·SE_N = 3.605·SE_N` (a two-sided 95 % CI test at 95 % power).

### 6.1 THE RESTART CURE GATE — the binding, band-edge gate (#120.2) ⚠⚠ TOP CHOICE

The residual sits ≈ AT the band edge, so it is by far the most power-hungry gate.

```text

residual R3p − R0 (anchor)      +139.075 ticks = +8.14 %       CI [+31.050, +236.558] = [+1.82 %, +13.84 %]  — straddles B (#120.2)
SE_120                          (236.558 − 31.050)/2 / 1.96  =  102.754 / 1.96  =  52.42 ticks
```

### 6.3 THE SIZING DECISION (proposed — flagged for the commander)

Sizing to the 95 %-power restart resolution means `N ≈ 4,240–7,600 / arm × 5 arms
= 21,200–38,000 matches` — a heavy battery (6.6–12× the P3a 3,200). Two honest
readings of the commander's intent (#120.2 "the exam this battery administers"):

1. **Administer the exam at ~95 % power.** Size to the smoke-fixed N* (§6.4), the
   restart residual resolved decisively above or below +10 %.
2. **Recognise that a full-power band-edge resolution of a MEASUREMENT battery's
   ONE knife-edge gate is disproportionate.** The restart residual's magnitude +
   CI is itself a REPORTED quantity (like the rest residual); its position relative
   to +10 % is read from the CI. A capped battery reports it honestly at whatever
   power the cap delivers.

**PROPOSED (flagged):** size via the §6.4 smoke + power rule targeting the restart
gate at ~95 %; **CAP N_MAX = 2,000 / arm** (matching the P3p-2 cap). At the cap:
`SE_2000 = 52.42·√(120/2000) = 12.84`, half-width 25.2 ⇒ restart residual CI ≈
`+139 ± 25 = [+114, +164] = [+6.7 %, +9.6 %]`, upper JUST below the +10 % edge ⇒
the cure would CERTIFY if the residual holds, at **~70 % power** (`Φ(31.809/12.84 −
1.96) = Φ(0.517) = 0.70`). **If the smoke's power rule projects N* ≤ 2,000 (lower
variance), run at N*; if it projects higher (the ~95 % target needs 4,240–7,600),
the cap binds and the reduced-power reading is DISCLOSED before the gate-bearing
run** (no optional stopping, #105.4). The restart cure gate then returns either
CERTIFIED (CI upper < +10 %) or UNRESOLVED-at-the-band-edge (CI straddles) — the
latter a legitimate MEASUREMENT outcome, the residual REPORTED with its CI
regardless. **This is the single most important sizing choice for the commander:
run the 21k–38k-match ~95 %-power battery, or cap at 2,000/arm (10,000 matches,
~70 % restart power) and read the residual from the CI.** I recommend the cap with
the reduced-power reading disclosed, because every OTHER gate + the primary
deliverable is over-powered at 2,000/arm, and the restart residual is a REPORTED
magnitude, not a hard stop.
